\# Django Application Deployment Using Docker, Jenkins, Terraform and AWS



\## Project Overview

This project demonstrates deploying a Django web application using Docker, Jenkins, Terraform, and Amazon Web Services (AWS).



\## Technologies Used

\- Python and Django

\- Docker

\- Jenkins

\- GitHub

\- GitHub Container Registry (GHCR)

\- Terraform

\- AWS EC2



\## Project Workflow

1\. Develop a Django web application.

2\. Push the source code to GitHub.

3\. Use Jenkins to build the Docker image.

4\. Push the Docker image to GHCR.

5\. Provision AWS infrastructure using Terraform.

6\. Pull the Docker image onto an EC2 instance.

7\. Run the container and access the application through a web browser.



\## Application Output
